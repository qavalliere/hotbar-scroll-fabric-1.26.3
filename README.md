# Hotbar Scroll Keys (Fabric 26.3) 🖱️🔄

Клиентский мод для Minecraft на базе **Fabric**, созданный специально для игроков, у которых **сломано или барахлит колёсико мыши**. 

Позволяет назначить **любые клавиши клавиатуры или боковые кнопки мыши** (Mouse 4, Mouse 5) для циклической прокрутки панели быстрого доступа (хотбара).

## ⚡ Особенности
- ✅ **Назначение любых кнопок**: клавиатура или дополнительные кнопки мыши (`Кнопка мыши 4` / `Кнопка мыши 5`).
- 🔄 **Бесшовная циклическая прокрутка**: со слота 9 сразу переходит на слот 1 и наоборот.
- 🛡️ **Чисто клиентский**: работает на всех серверах (Hypixel, ванильные серверы, одиночная игра) без необходимости установки на сам сервер.
- 🚫 **Не мешает интерфейсам**: если открыт чат, инвентарь или сундук, случайных переключений не происходит.

## 🛠️ Установка

1. Убедитесь, что у вас установлен **Fabric Loader** и **Fabric API** для вашей версии Minecraft.
2. Скачайте файл **`hotbarscroll-1.0.0-mc26.3.jar`**.
3. Поместите скачанный файл в папку с модами:
   - **Windows**: `%appdata%\.minecraft\mods`
4. Запустите Minecraft с профилем Fabric.

---

## ⚙️ Настройка управления

1. В игре перейдите в **Настройки → Управление → Назначение клавиш**.
2. В категории **Инвентарь** найдите:
   - `Предыдущий слот хотбара (влево)`
   - `Следующий слот хотбара (вправо)`
3. Кликните по ним и нажмите нужные клавиши (например, боковые кнопки мыши).
