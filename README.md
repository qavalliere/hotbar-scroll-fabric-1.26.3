# Hotbar Scroll Keys (Fabric Mod)

Клиентский мод для Minecraft на базе Fabric, позволяющий прокручивать хотбар назначенными кнопками (любыми клавишами клавиатуры или боковыми кнопками мыши).

## Возможности
- Назначение отдельных кнопок для прокрутки влево (предыдущий слот) и вправо (следующий слот).
- Поддержка боковых кнопок мыши (`Кнопка мыши 4`, `Кнопка мыши 5` и других).
- Циклическая прокрутка: с 9-го слота сразу на 1-й и наоборот.
- Не конфликтует при открытых меню (чат, инвентарь, сундуки).
- Чисто клиентский (можно играть на любых серверах).

## Как собрать mod .jar

1. Убедитесь, что установлена Java 21 (или Java 17 для более старых версий).
2. Откройте терминал в папке проекта:
   ```bash
   gradle build
   ```
   (или `./gradlew build`, если настроен Gradle Wrapper).
3. Готовый файл появится в папке `build/libs/hotbar-scroll-fabric-1.0.0.jar`.
4. Переместите этот `.jar` в вашу папку `.minecraft/mods`.

## Как изменить версию Minecraft
В файле `gradle.properties` можно поменять версии на нужные вам (например, под 1.20.4 или 1.21):
- `minecraft_version`
- `yarn_mappings`
- `fabric_version`
